HOW TO GENERATE UNLOCK CODES FOR THE VOUCHER TAB
=================================================

The Voucher tab is LOCKED on new downloads of the app.
To open it, each device needs its OWN unlock code.
Flow:  they send you a DEVICE CODE  ->  you send back an UNLOCK CODE
One unlock code works on ONE device only.


STEP 1 - THE CUSTOMER SENDS YOU THEIR DEVICE CODE
--------------------------------------------------
They open the app, tap the locked "Vouchers" tab, and the screen
shows their device code. It looks like this:

        ODU-4F2A-91C3-7B60

They copy it and send it to you (TikTok, WhatsApp, email) + pay you.


STEP 2 - YOU GENERATE THE UNLOCK CODE
--------------------------------------
Open a terminal in the odu-tracker folder and run:

        python3 tools/make_unlock_code.py ODU-4F2A-91C3-7B60

(Paste THEIR device code instead of the example.)

It prints:

        device code : ODU-4F2A-91C3-7B60
        unlock code : 538E-3FC2-6E4B-D7F0

That second line is all you need. The tool also prints a ready
reply message for you to copy.


STEP 3 - YOU REPLY TO THEM
---------------------------
Send only the unlock code:

        Your Vouchers unlock code is: 538E-3FC2-6E4B-D7F0
        Open the Vouchers tab, type it in, and it unlocks
        permanently on this device.


STEP 4 - THEY ENTER IT
-----------------------
1. Open the app -> Vouchers tab.
2. Paste the code into the "Unlock code" box.
3. Tap UNLOCK VOUCHERS. Done - it stays unlocked forever.


RULES / GOOD TO KNOW
--------------------
- One code = one device. A code for phone A will NOT open phone B.
- Codes never expire and never stop working.
- Pasting is safe: dashes, spaces, small letters all fine.
- Same phone after reinstall -> the same code works again.
- New phone / new download -> new device code -> you mint a new one.
- If a code leaks, it still only works on that exact device.


TEST IT ON YOUR OWN MACHINE
---------------------------
        python3 tools/make_unlock_code.py --here

Prints your own device code + the matching unlock code.
