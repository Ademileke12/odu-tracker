REDMI / MIUI WON'T INSTALL? OPEN THIS
  1. "Error while parsing package" almost always means the download was cut short, not a bad file. If your file is smaller than the size shown when downloads reopen, delete it and redownload.
  2. After downloading, open the APK from the Files app on the phone; the browser's own install prompt can leave a half file behind.
  3. Allow Settings → Apps → Manage apps → Files → Install unknown apps (or the browser you downloaded with).
  4. If MIUI's security scan warns, choose install anyway. The APK is CI-built from this repo's own release, nothing repacked.

When downloads reopen, every button here is a direct download — the browser saves the installer straight from GitHub's servers, no mirrors, no trackers. Never the “Source code (zip)” files, those are just the source, not the app.

// FIRST START

ONLINE IN THREE STEPS

  1. 01
    INSTALLRun the installer for your platform. Everything ships inside, no Python, no Node, no admin panel.
  2. 02
    CONNECTJoin the ODU's Wi-Fi / Ethernet. The app probes 192.168.0.1 and confirms it's really your ODU.
  3. 03
    DRIVESign in once with your ODU admin password, the app keeps its own session and starts logging immediately.
⚠ PENALTY BOX

The ODU firmware allows only 3 wrong login attempts, then locks the web login for ~26 h. The app stores your password locally and re-auths silently, so never brute-force it, in the app or anywhere else.
