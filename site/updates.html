// RELEASE LOG

THE CHANGELOG

Newest first. Same version on every platform - Windows, Linux, macOS and the Android APK are cut from one tag.

v1.5.0

24 Nov 2026 CURRENT
  • ₦2,500 one-time lifetime unlock - first launch shows the feature slides, then Paystack (card, transfer, USSD) unlocks the whole app on one device. No subscription, no grandfathering: older installs pay too.
  • Vouchers tab included - the guest-code feature folded into the single payment; no separate add-on any more.
  • Licence code survives reinstalls - copy it after paying, paste it back on the same device; useless on any other machine.
  • macOS Apple Silicon .dmg - first Mac build, straight from CI (unsigned for now: right-click → Open).
  • In-app update screen - a remote minimum-version switch can now force installs to update before anything else loads.
  • New homepage - slide-by-slide feature deck, pricing section, ChromeOS install notes; downloads paused until payment launch.

v1.4.1

23 Nov 2026
  • Default-deny guest Wi-Fi - new devices get no DNS, no web until they claim a voucher on the captive-portal page.
  • Safer arming - if the portal can't bind, nothing is saved: router DNS never moves, the toggle reverts, you get an alert.
  • Phone app: 4 tabs - Vouchers moved to the desktop app; Trust / Soft-cut / Block buttons fit their cards.

v1.4.0

13 Nov 2026
  • Vouchers go paid - per-device unlock codes, HMAC-verified offline; a remote kill-switch file can pause the feature or ban leaked codes in the field.
  • Shared SIM pool + quotas - cap data per code, revoke mid-stream, watch claims live.

v1.3.0

Android era
  • Fixed the Android boot crash - the app data dir now comes from p4a's ANDROID_PRIVATE instead of HOME, so the engine starts on phones.

older versions live in the repo's git tags - every build is reproducible from source.

// HOW UPDATES REACH YOUR INSTALL

UPDATED IN PLACE

No accounts, no auto-download surprises - you stay in control of when the app changes.

  1. 01
    THE APP ASKS FIRSTWhen a release raises the minimum version, your install shows a full-screen UPDATE REQUIRED before the dashboard or paywall - with a download button and a Check again that re-polls in real time. Ignore it and nothing else runs; that's the point.
  2. 02
    INSTALL OVER THE OLD ONEGrab the new build for your platform and install it on top - same app, same data, nothing to reconfigure. Windows keeps its settings, Linux re-installs the .deb, phones sideload the APK over the old one.
  3. 03
    YOUR LICENCE CARRIES OVERThe ₦2,500 unlock is bound to the device, not the install: your saved licence code re-activates after any update or reinstall. One payment, every version from now on.
